JvPaks Portfolio

1. Open this folder in VS Code.
2. Install the Live Server extension.
3. Right-click index.html -> Open with Live Server.
4. The site should open at http://127.0.0.1:5500/index.html.
5. To debug with F5, start Live Server first, then press F5.

Replace your.email@example.com in index.html with your real public email address.
